项目简介
“闪鲜日纪”是一个社交化的生鲜团购平台，主要面向需要拓宽销路的乡镇种植户、追求新鲜产品的社区居民，平台采用“以销定采”的模
式，连接产销两端，融合社交动态与团购预售，盈利来自交易佣金、广告服务、商家推广等。该系统采用 Java+Python 双引擎架构，Java 负责
核心交易与并发处理，Python 负责 AI 智能助手与 RAG 检索增强，实现业务与 AI 能力的解耦与深度融合。
工作内容
1. 私有化大模型智能助手微服务：负责智能助手微服务开发，从设计到落地，基于 LangChain 与本地大模型，采用 FastAPI+uvicorn 搭建，
对接 vLLM 私有化部署的 Qwen3-32B-Instruct 大模型，数据全程不出内网，兼顾数据隐私与零调用成本，智能助手微服务作为独立服务
与主平台通过 HTTP 解耦，支持不同角色用户的访问。
2. 动态提示词和持久化会话上下文：通过自定义 middleware（@dynamic_prompt 包装器），自动读取登录用户身份、权限信息动态拼接
系统提示词，适配差异化对话场景。基于 RedisChatMessageHistory 将用户会话上下文持久化到 Redis，支撑上下文内容连贯，兼顾性
能与可横向扩展。
3. 基于 Tool Calling 的业务工具调用：使用@tool 装饰器将订单查询、物流跟踪、团购库存、商品推荐等业务能力注册为大模型可调用工具，
依托原生 Tool Calling 让大模型自主判断调用时机。利用 ToolCallLimitMiddleware 限制单轮工具调用次数防止循环，基于登录 userId
做数据隔离，实现接口分级权限、数据自动脱敏，杜绝越权访问。
4. AgenticRAG 私有知识库检索：构建 AgenticRAG 检索增强，解决大模型私有知识缺失与上下文长度受限问题。文档经父子分块（父块保
上下文、子块提精度、建立层级回溯）后，通过本地部署的 bge-m3 模型同时生成稠密语义向量与学习型稀疏词权重向量，双路写入
Milvus（稠密字段 IVF_FLAT 索引+余弦相似度，稀疏字段 SparseInvertedIndex+IP 内积）。检索时通过 MilvusHybridSearch 并行执
行语义召回与关键词召回，融合候选集后由本地部署的 Reranker 模型精排 Top-K，最终结果由 Agent 按需调用生成回答。全程内网推理，
支持无重启热更新知识库，问答结果可溯源原文。
5. Elasticsearch 生鲜商品全文检索：搭建商品、种植户动态统一检索索引，实现商品与种植动态全文检索，采用“索引 ik_max_word 粗召
回+查询 ik_smart 精准匹配”的双层分词策略，结合 BM25 相关性算法实现多条件复合筛选，针对生鲜特有词汇构建自定义同义词库，进
一步优化搜索准确率与用户体验。
6. 分布式对象存储与异步内容审核：设计图片"先审后发"上传流程，前端通过阿里云 STS 临时凭证将图片直传 OSS 待审核 Bucket，避免服务
器 I/O 瓶颈。上传成功后，业务后端向 RabbitMQ 发送"待审核"消息，由审核消费者异步调用阿里云内容安全服务进行自动审核。审核通
过后，调用 OSS 的 CopyObject 将图片复制到公开 Bucket，更新状态为"已发布"，随后经 RabbitMQ 可靠消息异步更新 ES 索引和写入
MySQL 基础数据；审核拒绝则删除图片并向用户推送违规通知。
7. Redis 原子预扣库存和消息队列异步下单：团购开始前把库存同步到 Redis，用户下单时先用 Lua 脚本在 Redis 原子性扣减库存防超卖，扣
减成功发 MQ 由消费者异步创建订单写入数据库，业务层用 Redisson 分布式锁防止订单重复提交，DB 使用乐观锁进行兜底。
8. 延迟队列实现自动关单：用户下单时发送 30 分钟 TTL 消息到延迟队列，过期后进入死信队列，消费者检查订单状态，未支付则自动关单并
释放 Redis 预扣库存。采用乐观锁与状态前置校验防止并发冲突，只有状态匹配才能更新成功，配合定时任务补偿兜底，确保库存最终一致
性，跨服务订单、库存事务通过 SeataAT 分布式事务兜底，保障库存数据最终一致性。
9. 微信小程序双 Token 授权登录：实现微信小程序一键授权登录，基于 wx.login()获取 code 换取 openid，采用 AccessToken 和
RefreshToken 的双 Token 机制，短期令牌做接口权限校验，刷新令牌实现用户无感续登，兼顾接口安全性与使用体验。
